What I owned

Full system design and implementation of the NL-to-SQL pipeline, FAISS index strategy, NetworkX semantic graph, Azure DevOps pipeline, and CDC migration. Designed and shipped end-to-end without a dedicated AI team.

Key decisions

Chose FAISS over pgvector for offline-first retrieval at 6K column scale. Used NetworkX for semantic join graph over hardcoded paths to enable hot-reload domain onboarding. Chose Claude Sonnet over template SQL for intent-flexible generation with RLS wrapping.

What I'd do differently

Invest in catalog-first schema discipline earlier. The hot-reload domain onboarding gain came from treating the catalog as a product artifact, not a config file.
