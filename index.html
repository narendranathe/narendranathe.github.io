Payroll accrual and SECURE 2.0

PTO balances convert to cash at termination, so a defect in accrual logic is a payout rather than a display bug. I traced it to a payroll-period boundary calculation in SQL and put the fix through change-request review. SECURE 2.0 compliance went out in the same release train.

Failure detection and failover recovery

CDC capture jobs fail three ways: a run that never starts, a run that hangs, and a run that exits clean having captured nothing. Retention windows close and the change history inside them does not come back. Monitoring covers all three. Availability-group failover is written up as runbooks, including the post-failover capture failure that produces no error at all, and one live incremental-load failure was diagnosed and restored in place rather than falling back to a full reload.

CDC incrementals and idempotent provisioning

The CDC ETL reloaded whole tables on every run, and standing up a database was an hour of manual orchestration repeated twenty-plus times a day. Both failed in ways that needed a person to clean up before the next attempt. Moving CDC onto idempotent incremental merge-upserts brought runtime from 30 minutes to under 8 with compute down 67%, and the freshness SLA held through the change. Provisioning was rewritten to be safely rerunnable, closing four latent failure modes on the way: orphaned CDC cleanup jobs terminated properly, a guard that kills active replication sessions before disabling CDC, silently-defaulting restore parameters, and stuck-restore detection with pre-flight race checks.

Release ownership and the reporting layer

Releases went out roughly quarterly. Taking CI/CD through Azure DevOps brought the cycle to 14 days. Reporting moved onto Fabric semantic models with index and stored-procedure tuning underneath: query response 12s to under 4s.

Portfolio risk analytics

Kafka, Spark Structured Streaming, Delta, FastAPI, Streamlit

Market ticks come in through Kafka, Spark Structured Streaming aggregates them on 5-second tumbling windows behind a 10-second watermark, and a Delta writer lands the bronze layer. FastAPI computes VaR at 95% and 99% by historical simulation over a 30-day window rather than a parametric model, because equity returns are fat-tailed and a normal assumption understates the tail. Component VaR is computed per position, so the dashboard can name which holding is driving portfolio risk. On a fresh checkout the API falls back to a seeded sample set.
