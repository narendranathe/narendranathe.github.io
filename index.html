01 / CDC, validation & recovery

Build for the next run.

I reworked full-table reloads into rerunnable incremental merge-upserts. I built a control-table-driven validation framework, and a separate SSISDB procedure that gives engineers package execution evidence for failed-job investigations.

The decisions: process changes, make reruns safe, and define checks as configuration.

When an incremental load failed in production, I diagnosed it and restored that path in place. The operational consequence matters: reporting teams need current data, and engineers need a recovery path they can explain.
