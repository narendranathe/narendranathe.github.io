Version-controlled session context

The package combines repository documents, lifecycle scripts, CLI checks and local operational telemetry. Selected context can be supplied to the coding agent when a session begins.

Developers or agents author decisions and rationale. The package preserves those notes in files rather than reconstructing decisions from conversation history.

Design decisions

01 / Storage

Keep context with the code

Version-controlled files make intent, decisions and next steps inspectable alongside implementation changes. The handoff still depends on someone recording useful reasoning.

02 / Integration

Use host lifecycle hooks

Claude has lifecycle integration. Other platform integrations are partial and depend on what the host exposes; they are not equivalent implementations.

03 / Dependencies

Use Python’s standard library

The runtime has no third-party Python dependencies. Python and Git still need to be available in the installed hook environment.

repo-context-hooks verify --platform claude

The workspace contract includes README.md, specs/README.md and UBIQUITOUS_LANGUAGE.md. Developers or agents record semantic decisions in authored notes.

Verification checks synthetic telemetry plumbing and settings. Dashboard time, token and cost savings are estimates based on fixed assumptions. Telemetry is local JSONL; selected context is supplied to the coding agent.
