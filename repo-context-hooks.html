README.md / product intent

What are we trying to build?

Keep a reviewer-oriented explanation of the product and its purpose next to the source.

The next session can start with the intended outcome instead of guessing from a diff.

Illustrative content in the tool's file-based handoff pattern. This is a frontend explanation, not a live agent session or a recording of one.

Make the handoff something you can read.

The package combines repository documents, lifecycle scripts, CLI checks, and local operational telemetry. Selected context can be supplied to the coding agent when a session begins or context changes.

Semantic decisions still need an author. A developer or agent records what was decided and why. The tool does not infer that meaning from a full conversation.

Three boundaries I chose to keep.

01 / Reviewable memory

Keep context with the code.

Repository files can be read, versioned, and reviewed alongside the change. The tradeoff is maintaining the handoff instead of treating memory as magic.

02 / Honest integration

Match the host's capabilities.

Claude has lifecycle integration. The other documented platforms use partial instruction or export paths, not equivalent automatic hooks.

03 / Small runtime

Use Python's standard library.

The package declares no third-party runtime dependencies. Python and Git still need to be available in the installed hook environment.

Setup, verification, and measurement details
python -m pip install repo-context-hooks
repo-context-hooks install --platform claude
cd /path/to/your/repository
repo-context-hooks init
repo-context-hooks verify --platform claude
repo-context-hooks measure --repo-root .

Installation changes the selected agent's configuration. Use an environment you choose to configure. The workspace contract includes README.md, specs/README.md, and UBIQUITOUS_LANGUAGE.md. Record semantic decisions with checkpoint --message or agent-authored notes.

The verify command checks synthetic telemetry plumbing and settings. It does not prove all host lifecycle events occurred. Dashboard time, token, and cost savings use fixed assumptions, not timed measurements or actual bills.

Telemetry is local JSONL, with no remote collector implementation in the reviewed source. Selected context intentionally reaches the coding agent, and optional GitHub CLI calls can read issue metadata.
