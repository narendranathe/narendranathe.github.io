Idempotent ETL and data quality

I build and support SQL Server and Azure workflows for CDC ingestion, data validation, execution diagnostics and incident recovery.

My responsibilityIngestion design, validation tooling, diagnosis & recovery
UsersData engineers, IT & reporting teams
Core stackSQL Server · SSIS/SSISDB · Azure DevOps

Context and constraints

HR and payroll reporting depends on current, consistent warehouse data. Full-table reloads repeat work on unchanged records, while a failed incremental load can interrupt the reporting path.

I reengineered CDC ingestion, built a metadata-driven validation framework and created a separate SQL procedure for package execution diagnostics. The tools address different responsibilities: data movement, correctness and investigation.

Design decisions

01 / CDC ingestion

Idempotent incremental processing

I replaced full-table reloads with incremental merge-upserts that can rerun cleanly without manual cleanup. The tradeoff is careful handling of change-tracking state and partially applied work.

02 / Data quality

Metadata-driven validation

I built a control-table-driven framework so a new check can be defined through configuration. Rules encode the expected data conditions and need engineering review as those conditions change. The framework is deployed in shared test.

03 / Failure diagnosis

SSISDB execution diagnostics

I built a stored procedure that exposes which packages ran, when they ran and execution evidence around failed SQL Agent jobs. It supports investigation; engineers decide how to recover.

Production support and release operations

Incremental-load recovery

I diagnosed a live incremental-load failure and restored the incremental path without a full reload. I also document CDC and availability-group recovery procedures so another engineer can follow the response.

Azure DevOps CI/CD

I own release automation for SSRS and Power BI and coordinate delivery across development, test, IT and business. Python workflows using Git and Azure DevOps APIs provide delivery visibility. AI-assisted changes go through review and tests.

Outcomes

CDC loads became incremental and idempotent. The shared-test validation framework made checks configurable, while the SSISDB procedure supplied package-level evidence for failed-job investigations. These changes give engineers explicit ways to load, validate and troubleshoot the reporting data other teams use.
